FAQ

Questions

Do players need to install the mod?

Not on a server: vanilla 26.2 players can join and use the chest menus. Install it in your game too and you get the custom duel menu.

How do I play with just a friend?

Download the Friends Edition. You both install it, one opens a singleplayer world and clicks Open to LAN, the other joins, then press U to challenge. The Friends Edition will not run on dedicated servers. Use the Server Edition for those.

Will I lose my items?

No. Your inventory, XP, effects, health and position are saved before the duel and restored after, even if you disconnect or the server stops.

Where are the maps built?

Far away in the overworld (around x = 1,000,000), so they never touch your builds. Each map is built once, then reused.

Can I add my own kits and maps?

Yes. Hold a shulker and run /duel kit save name for a kit. For a map, build it, mark it with /duel arena pos1/pos2/spawn1/spawn2 and run /duel arena save name.

What can I configure?

Countdown length, round time limit, ELO settings, default kit, fireworks, the health bar and ranked announcements, all in config/duelarena/config.json.
